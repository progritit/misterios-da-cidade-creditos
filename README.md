# Mistérios da Cidade · Créditos e fontes

Repositório público separado para as fontes, autorias e condições de uso dos materiais citados em cada obra de Mistérios da Cidade.

**Escopo:** cada página reúne referências e créditos próprios. Sua publicação não concede uma licença global sobre documentários, narrações, músicas, identidade visual ou materiais de terceiros.

## Estrutura

- `docs/index.html`: índice dos episódios.
- `docs/ep004.html`: Paranapiacaba.
- `docs/ep005.html`: Fordlândia.
- `docs/ep006.html`: Barra do Garças e Serra do Roncador.
- `docs/ep007.html`: Recife: A Emparedada da Rua Nova — fontes do documentário e dos dois curtas.
- `docs/style.css`: estilo responsivo compartilhado.

A página EP007 mantém visíveis as reservas ainda abertas e distingue referências documentais, arquivos, materiais contemporâneos, reconstituições, narração, música e identidade sonora. As páginas não substituem a verificação das licenças nem a aprovação dos titulares.

## GitHub Pages

O site usa a pasta `/docs` na branch `main`. Antes de incluir uma URL em metadados, confirme a publicação, o conteúdo, HTTPS e resposta HTTP 200. Uma página local, branch ou pull request não comprova publicação ou clearance.
